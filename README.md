# WordPocket

Личное Android-приложение для изучения английских слов и фраз. Интерфейс на русском: бумажный фон, терракотовые акценты, книжные заголовки и короткие занятия. Концепция карточек вдохновлена ReWord; название, интерфейс и исходники проекта самостоятельные.

## Текущее состояние

Нативный интерфейс перенесён из [дизайн-прототипа](design/index.html) по [плану](Plan.md): библиотека, словарь, занятие, результат и формы. Сохранены системная тёмная тема, данные Room и формат JSON. Описание переноса и сравнительные снимки: [docs/DESIGN.md](docs/DESIGN.md). Актуальные результаты проверок и путь к APK: [docs/BUILD.md](docs/BUILD.md). Ручная приёмка на Android-устройстве пока не выполнена.

Установочный файл с новым интерфейсом: **`WordPocket-0.1.0-debug.apk`** в корне проекта; тот же APK находится в `app/build/outputs/apk/debug/app-debug.apk`. Использован прежний debug-ключ.

## Возможности

- Создание, переименование и удаление тематических словарей.
- Добавление, редактирование и удаление слов и целых фраз.
- Обязательные поля: английский текст и перевод. Необязательное: транскрипция.
- Импорт JSON в выбранный словарь с проверкой файла и пропуском дубликатов.
- Экспорт содержимого словаря в JSON (без прогресса обучения).
- Изучение порциями: размер пула от 1 до 100 карточек, по умолчанию 10.
- Выбор одного из четырёх вариантов, письменный ответ, кнопка «Пока не знаю».
- Мгновенный переход после правильного выбора; ручной разбор остальных ответов.
- Повторение только выученных карточек выбранного словаря.
- Локальное сохранение словарей, прогресса и текущих пулов в Room/SQLite.
- Поиск и фильтры карточек, светлая и тёмная темы по настройке телефона.
- Приложению не нужен интернет. Регистрации нет.

## Правила тренировки

**Направление:** приложение показывает русский перевод, пользователь отвечает по-английски. После верного выбора из четырёх вариантов сразу открывается следующий вопрос (или итог занятия). После письменного ответа, ошибки или «Пока не знаю» открываются правильный ответ, транскрипция и кнопка «Продолжить». Ошибочный и правильный варианты выделяются разными цветами. Это поведение одинаково для изучения и повторения.

**Изучение:** при запуске выбираются первые N ещё не выученных карточек по порядку добавления. Это фиксированная порция: выученные карточки уходят из пула, новые автоматически не подставляются. После трёх правильных ответов подряд на разных показах карточка получает статус «Выучено». Ошибка или «Не знаю» сбрасывает серию в ноль. Незакреплённая карточка переносится в конец очереди. После опустошения пула занятие завершается; следующая порция запускается отдельно.

Каждый ответ сохраняется сразу в транзакции. После закрытия приложения можно продолжить пул с учётом последнего сохранённого ответа. Изменение размера пула применяется к следующей порции.

Каждый показ карточки имеет свой номер, даже если в пуле одно слово. Повторные и запоздалые нажатия не засчитывают ответ дважды. При ошибке записи вопрос остаётся доступен для повторного ответа; при ошибке загрузки после сохранения кнопка «Повторить загрузку» повторяет только чтение.

**Повторение:** очередь состоит исключительно из выученных карточек одного выбранного словаря и перемешивается в начале занятия. Верный ответ убирает карточку из текущей очереди. Ошибка возвращает её в конец очереди, сохраняя статус «Выучено». Повторение завершается после правильного ответа на каждую карточку. При выходе очередь повторения не сохраняется; новое занятие снова охватывает все выученные карточки словаря.

**Проверка ввода:** регистр, пробелы по краям, повторные пробелы и варианты апострофа не учитываются. Пунктуация и написание должны совпадать с карточкой. Например, для `How are you?` знак вопроса обязателен. Синонимы и альтернативные ответы автоматически не определяются.

**Варианты ответа:** неправильные варианты берутся из того же словаря, включая новые и выученные карточки. Это не добавляет новые карточки в очередь повторения. Дубликаты английского ответа и карточки с тем же переводом исключаются. Если невозможно выбрать три различных неправильных ответа, доступен письменный режим.

Изменение английского текста или перевода карточки сбрасывает её прогресс; изменение только транскрипции его сохраняет. Удаление слова из активного пула уменьшает размер этого занятия. Одинаковые слова в разных словарях имеют независимый прогресс.

## JSON

Пример с 12 карточками: `examples/travel.json`. Формальное описание: `examples/words.schema.json`.

```json
{
  "words": [
    { "word": "journey", "translation": "путешествие", "transcription": "/ˈdʒɜːni/" },
    { "word": "How are you?", "translation": "Как дела?" }
  ]
}
```

В приложении открой нужный словарь → «Импорт JSON» → выбери файл. Для импорта используется системный выбор документа; доступ ко всем файлам телефона не запрашивается.

Ограничения: UTF-8; файл до 2 МБ; от 1 до 10 000 карточек; английский текст до 300 символов, перевод до 500, транскрипция до 300. Поле `transcription` можно опустить или оставить пустой строкой. `null` и числовые поля не принимаются. Неизвестные поля игнорируются.

Файл проверяется полностью до записи. Ошибка в любой карточке отменяет весь импорт. Запись выполняется одной транзакцией. Дубликат определяется по паре «английский текст + перевод» без учёта регистра и лишних пробелов, внутри выбранного словаря. Импорт не перезаписывает существующие карточки или их прогресс. В конце показывается число добавленных и пропущенных карточек.

Экспорт предназначен для переноса словарного содержимого, а не для резервного копирования прогресса. Данные приложения локальные: удаление приложения удаляет базу; системное резервное копирование отключено.

## Технологии и структура

- Android 8.0+ (minSdk 26), compileSdk/targetSdk 35.
- Kotlin 2.1.20, Jetpack Compose (BOM 2025.04.01), Material 3.
- Room 2.7.1, KSP 2.1.20-1.0.32.
- Android Gradle Plugin 8.9.2, Gradle 8.11.1, JDK 17.
- JSON обрабатывается kotlinx.serialization без рефлексии.

```text
app/src/main/java/app/wordpocket/
  MainActivity.kt           — вход в приложение
  WordPocketApp.kt          — создание базы и репозитория
  data/AppDatabase.kt       — таблицы, внешние ключи и DAO
  data/WordRepository.kt    — операции и транзакции обучения
  data/WordJson.kt          — проверка, импорт и экспорт JSON
  domain/Learning.kt        — проверка ответа и правила запоминания
  ui/AppViewModel.kt        — состояние экранов и занятия
  ui/Screens.kt             — навигация и системный выбор файлов
  ui/LibraryScreen.kt       — библиотека
  ui/DictionaryScreen.kt    — словарь, поиск и список карточек
  ui/TrainingScreen.kt      — занятие, разбор и итог
  ui/Components.kt          — общие компоненты оформления
  ui/Dialogs.kt             — формы и подтверждения
  ui/Theme.kt               — палитры и типографика
app/src/test/              — модульные тесты логики и JSON, настройки Robolectric
app/src/androidTest/       — общие сценарии Compose/Room для Android и JVM
examples/                  — пример словаря и JSON Schema
.github/workflows/         — будущая облачная сборка по ручному запуску
```

База содержит три таблицы: `dictionaries`, `words`, `pool`. Индекс пары `(dictionaryId, identity)` предотвращает дубликаты; внешние ключи удаляют зависимые записи вместе со словарём. Очередь изучения хранится в базе, очередь повторения — в ViewModel. При повороте экрана ViewModel сохраняет занятие.

## Будущая сборка в облаке

Workflow `.github/workflows/android.yml` подготовлен, но не запускался и в GitHub не загружался. Он имеет **только ручной триггер** `workflow_dispatch`: обычный push сам по себе сборку не запускает.

Когда потребуется APK:

1. Поместить проект в выбранный GitHub-репозиторий с включёнными Actions; workflow должен находиться в основной ветке.
2. Открыть Actions → Android APK (manual) → Run workflow.
3. Задача установит JDK/SDK, запустит модульные тесты, Android Lint и соберёт debug APK.
4. Скачать артефакт `WordPocket-debug-apk`. Внутри будет `app-debug.apk`.

В комплекте исходный загрузчик Gradle: `gradlew` для Linux/macOS и `gradlew.bat` для Windows. Первый вызов скачивает официальный `gradle-wrapper.jar`, проверяя закреплённый SHA-256. Затем Wrapper скачивает Gradle 8.11.1 с проверкой SHA-256 дистрибутива. Бинарные зависимости не включены в исходники. На Linux workflow вызывает `bash gradlew`, поэтому исполняемый бит файла не обязателен. Linux-загрузчик проверен при локальной сборке; Windows-загрузчик ещё не проверялся.

Debug APK предназначен для личного тестирования. Ключ текущей локальной сборки сохранён в `.android/debug.keystore` (папка исключена из Git). Для обновления установленного приложения используйте тот же ключ; для локальных сборок задавайте `ANDROID_USER_HOME` равным пути к этой папке. Стандартный debug-ключ одноразового облачного runner может отличаться между сборками. Release-подпись в проект не добавлена.

Совместимость AGP/Gradle/JDK сверена с [документацией Android](https://developer.android.com/build/releases/agp-8-9-0-release-notes); контрольные суммы — с [официальным списком Gradle](https://gradle.org/release-checksums/).

## Что проверить после первой сборки

Исходные 12 модульных тестов покрывают правила обучения и JSON. Дополнительные сценарии Compose/Room проверяют автопереход, письменный режим, фиксированный пул, устаревшие события, ошибки записи и повторную загрузку. Они запускаются и через Robolectric в `testDebugUnitTest`, и на устройстве через `connectedDebugAndroidTest`.

```bash
bash gradlew --no-daemon testDebugUnitTest lintDebug assembleDebug
bash gradlew connectedDebugAndroidTest
```

Первый запуск Robolectric скачивает Android runtime и требует интернета; само приложение работает офлайн. Снимки экранов JVM-проверки сохраняются в `app/build/screenshots/`. Устройство или эмулятор требуется только для второй команды.

Ручные сценарии на Android описаны в `docs/ACCEPTANCE.md`. Особенно важны сохранение пула после перезапуска, изоляция словарей и работа импорта через системный выбор файлов.
