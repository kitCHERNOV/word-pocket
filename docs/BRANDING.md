# КитЛэнг

## Краткий разбор проекта

Офлайн-приложение для изучения английских слов и фраз, один Android-модуль `app`, Kotlin, Jetpack Compose и Room. Минимальная версия Android — 8.0 (API 26).

- `data/`: словари, карточки, очередь изучения, настройки, импорт и экспорт JSON. Изменения прогресса сохраняются в транзакциях; база версии 2 имеет миграцию с версии 1.
- `domain/`: нормализация ответов, проверка карточек, подсчёт серии правильных ответов, подбор вариантов ответа. Правила отделены от Android-интерфейса.
- `ui/`: библиотека, словарь, тренировка, диалоги и состояние ViewModel. Настройка темы хранится в SharedPreferences.
- `design/`: самостоятельный HTML-прототип с собственным локальным хранилищем.
- Проверки: JUnit, Robolectric и общие сценарии Compose/Room, доступные также для запуска на устройстве.

Для нового названия достаточно обновить подпись приложения, шапку и графические ресурсы. Идентификатор `app.wordpocket`, имя базы `word-pocket.db` и существующие настройки сохранены для совместимости обновления. Схема Room остаётся версии 2.

## Название и логотип

Название для пользователя — **КитЛэнг**, источник в Android: `res/values/strings.xml`, строка `app_name`. Эту строку используют манифест и шапка главного экрана. Предлагаемое имя экспортируемого словаря — `kitlang-<id>.json`.

Логотип вручную воспроизведён в векторе по предоставленному изображению: улыбающийся оранжевый кит, кремовое брюшко и тёмный плавник. Мягкие градиенты передают цвет образца; растровая фактура исходной картинки в вектор не переносилась.

- [SVG-оригинал](../design/kitlang-logo.svg) — прозрачный фон; используется также в HTML-прототипе.
- `res/drawable/ic_kitlang.xml` — цветной VectorDrawable для Compose, без тонирования.
- `res/drawable/ic_launcher_foreground.xml` — цветной передний слой адаптивной иконки.
- `res/drawable/ic_launcher_monochrome.xml` — монохромный слой для тематических значков Android 13+.
- `res/mipmap-anydpi/ic_launcher.xml` — адаптивная иконка с цветным и монохромным слоями. Фон — `#F4EFE8`. Общий ресурс подходит всему поддерживаемому диапазону API 26+; тематические значки используют монохромный слой на Android 13+.

Контур кита в иконке размещён внутри центральной безопасной окружности диаметром 66 из 108 единиц. Цветной и монохромный слои используют одинаковый масштаб. При дальнейшей правке формы нужно синхронно обновлять SVG и три VectorDrawable.

Структура ресурса соответствует [документации Android по адаптивным иконкам](https://developer.android.com/develop/ui/compose/system/icon_design_adaptive).

В шапке кит расположен рядом с названием. При доступной ширине меньше 340 dp после отступов или масштабе шрифта больше 130% кнопки темы, настроек и создания словаря переходят во вторую строку. Области нажатия остаются 48 dp.
