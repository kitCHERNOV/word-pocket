## Инструменты, данные и подпись

Использованы JDK Temurin 17.0.21, Gradle 8.11.1, Android SDK Platform 35 и Build Tools 35.0.0. Robolectric 4.14.1 исполняет общие Compose/Room-сценарии на JVM с Android API 35 и нативной графикой. Основная фикстура — временная Room-база в памяти, без обращения к пользовательской базе.

Для прогонов Robolectric ожидание обрабатывает главный поток Android, на который Room возвращает результаты корутин. Снимки снимаются через отрисовку окна в Bitmap, чтобы избежать зависания PixelCopy при отсутствии реального дисплея.

Схема Room, история схем, нормализация, правила обучения и JSON не изменены. Дополнены только создание словаря с явным размером пула и доступность внедрения тестового репозитория.

Debug-ключ сохранён в `.android/debug.keystore` и исключён из Git. При локальной сборке `ANDROID_USER_HOME` указывал на папку `.android` проекта.
