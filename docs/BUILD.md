## Воспроизведение

Нужны JDK 17, Android SDK Platform 35 и Build Tools 35.0.0. Локально использован Temurin 17.0.21. Для обновления установленной debug-сборки задавайте `ANDROID_USER_HOME` равным папке `.android` проекта с прежним ключом.

```bash
bash gradlew --no-daemon testDebugUnitTest
bash gradlew --no-daemon lintDebug assembleDebug
bash gradlew --no-daemon assembleDebugAndroidTest
# После подключения устройства:
bash gradlew --no-daemon connectedDebugAndroidTest
```

Проверки выполнены отдельными прогонами с `--max-workers=2` и `-Pkotlin.compiler.execution.strategy=in-process`. Все зависимости были доступны в локальном кэше. GitHub Actions не запускался, исходники не публиковались.
